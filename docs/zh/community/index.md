# 社区

本页说明如何与 jsMind V2 项目交流、如何贡献、如何获得支持，以及（如果有的话）如何赞助。下面的链接都来自本仓库或项目的 GitHub 页面中已经存在的地址。项目没有单独的 Discord、Slack、论坛或邮件列表。

## 交流

讨论发生在 GitHub 上。

- 在 [jsMind V2 议题跟踪](https://github.com/hizzgdev/jsmind-v2/issues) 中提问、报告缺陷或提出功能建议。`package.json` 的 `bugs.url` 也指向这个地址。
- 项目仓库是 [hizzgdev/jsmind-v2](https://github.com/hizzgdev/jsmind-v2)。

本仓库未启用 GitHub Discussions。项目目前也没有公开的聊天室、论坛或邮件列表。

npm 包的作者信息中列出的邮箱是 [hizzgdev@163.com](mailto:hizzgdev@163.com)。库里的 `JsMind.Author` 也是同一地址。

## 贡献

欢迎通过 [Pull Request](https://github.com/hizzgdev/jsmind-v2/pulls) 向 [hizzgdev/jsmind-v2](https://github.com/hizzgdev/jsmind-v2) 贡献。

本仓库目前没有单独的 `CONTRIBUTING` 文件。若要从源码构建，请按[快速上手](/zh/guide/getting-started)或仓库 [README](https://github.com/hizzgdev/jsmind-v2/blob/master/README.zh.md) 中的步骤操作：需要 Node.js >= 22.12.0，然后执行 `npm install` 和 `npm run build`。

本项目以 [BSD 3-Clause License](https://github.com/hizzgdev/jsmind-v2/blob/master/LICENSE) 开源。

## 赞助

仓库目前没有公布资助或赞助链接：没有 `.github/FUNDING.yml`，`package.json` 也没有 `funding` 字段。如果想支持这个项目，可以给仓库加星、提出有用的议题，或提交 Pull Request。

## 支持

- 对外文档站：[https://hizzgdev.github.io/jsmind-v2/docs/](https://hizzgdev.github.io/jsmind-v2/docs/)
- 在浏览器里试用库的 [Playground](https://hizzgdev.github.io/jsmind-v2/playground.html)
- 仓库里的 [skill](/zh/guide/skill)，用于借助 CLI 画图或改图
- 报告缺陷和提问请使用 [GitHub Issues](https://github.com/hizzgdev/jsmind-v2/issues)

仓库里没有列出单独的商业支持渠道。
