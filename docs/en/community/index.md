# Community

This page lists the public ways to talk with the jsMind V2 project, contribute, get support, and — if one exists — sponsor the work. Every link below is a channel that already appears in this repository or on the project's GitHub page. There is no separate Discord, Slack, forum, or mailing list.

## Communication

Conversation happens on GitHub.

- Open or follow an issue in the [jsMind V2 issue tracker](https://github.com/hizzgdev/jsmind-v2/issues). Use issues for bug reports, questions, and feature proposals. The same URL is listed as `bugs.url` in `package.json`.
- The project repository is [hizzgdev/jsmind-v2](https://github.com/hizzgdev/jsmind-v2).

GitHub Discussions is not enabled on this repository. The project does not currently publish a chat room, forum, or mailing list.

The npm package metadata lists the author's email as [hizzgdev@163.com](mailto:hizzgdev@163.com). The `JsMind.Author` value in the library is the same address.

## Contributing

Contributions are welcome as [pull requests](https://github.com/hizzgdev/jsmind-v2/pulls) against [hizzgdev/jsmind-v2](https://github.com/hizzgdev/jsmind-v2).

This repository does not currently include a separate `CONTRIBUTING` file. To build from source, follow the install steps in the [Getting Started](/en/guide/getting-started) guide, or in the repository [README](https://github.com/hizzgdev/jsmind-v2/blob/master/README.md): you need Node.js >= 22.12.0, then `npm install` and `npm run build`.

The project is open source under the [BSD 3-Clause License](https://github.com/hizzgdev/jsmind-v2/blob/master/LICENSE).

## Sponsorship

The repository does not currently publish a funding or sponsorship link: there is no `.github/FUNDING.yml`, and `package.json` has no `funding` field. If you want to support the project, you can star the repository, open useful issues, or contribute pull requests.

## Support

- The public documentation site: [https://hizzgdev.github.io/jsmind-v2/docs/](https://hizzgdev.github.io/jsmind-v2/docs/)
- The [Playground](https://hizzgdev.github.io/jsmind-v2/playground.html), where you can try the library in the browser
- The repository [skill](/en/guide/skill), for drawing or editing a map with the CLI
- [GitHub Issues](https://github.com/hizzgdev/jsmind-v2/issues) for bugs and questions

There is no separate commercial support channel listed in the repository.
