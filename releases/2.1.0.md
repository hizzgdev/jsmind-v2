# jsMind 2.1.0

Minor release on the 2.x preview line (npm tag `v2-preview`). The minor carries breaking changes, so read the list below before upgrading.

## Install

```bash
npm i jsmind@2
```

`npm i jsmind` still installs v1 (0.9.x).

## What changed

### Breaking

- `mind add-child --side` on a parent below the root now exits with `2`. A side is the position of a root's direct children — the whole subtree inherits it — so the option did nothing anywhere else. It is a usage error now, and the message names the first-level branch the node belongs to (#134).
- `mind add-node` is gone. `mind add-child` is the same command; `--side`, `--position` and `--folded` are the old `addNode` destination and node options (#134).

### Features

- feat(cli): report unknown options, add --strict and --version (#136)
- feat(export): add opt-in transparent PNG background (#132)
- feat(cli): add document-level defaultTone and a mind style set command (#131, renamed to `mind set-style` in #141)
- refactor(cli): rename mind style set to mind set-style (#141)

### Fixes

- fix(cli): widen and report the browser start timeout (#145)
  - `jsmind export` now waits up to 60s for Chrome (override with `JSMIND_BROWSER_START_MS`), and a failure prints the tail of Chrome's stderr instead of only "did not start in time".

Node.js `>=22.12.0` is required (`engines.node` in package.json). npm only warns when the range is not met, so this is worth checking before installing.
