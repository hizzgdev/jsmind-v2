jsMind V2

A mind-map kernel for people and agents: people can view, edit and export maps; agents can reliably create, read and modify them.

2.x preview — the API may still change between minor releases.

  • Documentation Installation, the API reference and the design notes.
  • Tutorials One task, start to finish, with example files.
  • Playground Open a mind map in the browser and edit it.

Install

npm i jsmind@2

Quick start has the full steps; this page does not repeat them.
